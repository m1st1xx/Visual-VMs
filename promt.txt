хочу реализовать такую визуально понятную программу на windows которая будет работать вместе с VMware.
Нужно реализовать следующий функционал:
создание:
	при нажатии кнопки создать появляется форма где нужно указать имя устройства путь к iso файлу выделяемые мощности то есть спрашивает сколько выдать 	озу и ядер, спрашивает объем диска, и спрашивает предназначение это нужно для визуального отображения, дальше данные из формы передаются в VMware и 	она создает виртуальную машину по параметрам из заполненной формы
добавление: 
	если в VMware уже существуют машины, их можно добавить, программа обратиться к VMware чтобы посмотреть какие виртуальные машины существуют, далее 	программа предоставит список доступных вм и можно выбрать галочками какие вм добавить, это нужно для того чтобы за раз можно было добавить несколько вм,
	после того как пользователь выбрал все виртуальные машины ему нужно выбрать предназначения для каждой вм.
Удаление:
	при удалении вм в программе она отправляет запрос на удаление вм в VMware
предназначения:
	роутеры серверы и клиенты(пк) и интернет(иконка облачка)
	нужно сделать минималистичную иконку для каждого варианта
функционал:
	при нажатии пкм в свободном месте на поле
	отображается панель с несколькими кнопками:
		создать вм
		добавить вм
		удалить вм
		сеть вм
работа с сетью:
	при нажатии кнопки сеть вм между собой появляется выбор: соединить напрямую или соединить несколько или удалить подключение, если пользователь выбрал соединить напрямую то от устройства начинает тянутся проводок потом он выбирает конечную вм и при нажатии на конечную вм всплывает окно с подтверждением соединения, если пользователь нажал да, то в vmware в настройках обеих вм добавляется lan segment с названием состоящим из соединенных имен вм с помощью - допустим соединил router1 и router2 на обеих вм появился lan segment router1-router2, если пользователь нажимает на кнопку соединить несколько, всплывает окно где нужно указать название сегмента, после чего на рабочей зоне программы появляется круг с названием сегмента при нажатии на этот круг появляется проводок который можно подключить к вм, после присоединения каждой вм к кругу у вм в VMware создается lan segment с названием сегмента из программы, соответственно если мы добавили 3 вм то на всех трех вм добавить lan segment с названием сегмента из программы, если у вм есть адаптер NAT то программа автоматически рисует проводок между вм и иконкой интернета, при нажатии удалить подключение выбираем подключение которое хотим удалить и на всех вм в vmware удаляется адаптер который использовал это подключение
при добавлении готовых вм программа проверяет все lan сегменты которые есть у вм в VMware и логически соединяет их проводами
