# Visual VMs

Визуальная схема сети для VMware Workstation в стиле Cisco Packet Tracer: ВМ — это значки на поле, сеть — провода между ними.

## Возможности

- ПКМ по пустому месту: **Создать вм**, **Добавить вм**, **Удалить вм**, **Сеть вм** (Соединить напрямую / Соединить несколько / Удалить подключение).
- **Создать вм** — форма (имя, система, ISO, ОЗУ, ядра, диск, предназначение). Программа сама пишет .vmx, создаёт диск через `vmware-vdiskmanager` и открывает ВМ в VMware (она попадает в библиотеку). Новая ВМ получает адаптер NAT — провод к облаку «Интернет».
- **Добавить вм** — список ВМ из библиотеки VMware, галочки и предназначение для каждой.
- **Удалить вм** — «Убрать со схемы» или «Удалить с диска» (`vmrun deleteVM`, включённая ВМ сначала выключается).
- **Соединить напрямую** — провод между двумя ВМ: на обеих появляется LAN segment `имя1-имя2`. Провод к облаку — адаптер NAT.
- **Соединить несколько** — круг-сегмент с заданным именем; провода от круга к ВМ добавляют им этот LAN segment.
- **Удалить подключение** — удаляет у ВМ адаптеры, которые использовали это подключение.
- Провода строятся по .vmx файлам: при открытии, добавлении и по **F5** программа перечитывает все ВМ.
- Значки: роутер, сервер, клиент (ПК), облако. Точка у значка: зелёная — включена, серая — выключена, красная — файл не найден.
- Двойной щелчок по ВМ — консоль VMware. ПКМ по ВМ — Включить / Выключить / Открыть консоль / Удалить.
- Схема сохраняется в файл `*.vvm` (меню «Файл»); последняя схема открывается при запуске.

## Сборка и запуск

Нужны Windows, .NET 8 SDK и VMware Workstation.

```
dotnet build VisualVMs.sln
dotnet test VisualVMs.sln
dotnet run --project src\VisualVMs
```

## Важно

- **Закройте вкладку ВМ в VMware перед изменением сети** (и перед удалением с диска). Включённые ВМ программа предложит выключить сама.
- Имена LAN-сегментов хранятся в `%APPDATA%\VMware\preferences.ini`. Если VMware Workstation открыт, он может перезаписать файл и имя сегмента пропадёт из VMware (сеть при этом работает). Программа восстанавливает имена сегментов из схемы при её открытии, если VMware закрыт.
- Перед каждой правкой рядом с файлом создаётся копия `*.vvm.bak`.
- Приостановленные и зашифрованные ВМ программа не изменяет.
