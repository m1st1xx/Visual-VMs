# Visual VMs

Визуальная схема сети для VMware Workstation в стиле Cisco Packet Tracer: ВМ — значки на поле, сеть — провода между ними. Программа не держит свою копию сети: провода всегда строятся по `.vmx` файлам, а изменения сети записываются прямо в `.vmx` (адаптеры `ethernetN.*`) и в `%APPDATA%\VMware\preferences.ini` (имена LAN-сегментов).

**Скачать:** [dist/VisualVMs.exe](dist/VisualVMs.exe) (portable: один файл, без установки и без прав администратора). **Инструкция пользователя:** [docs/USAGE.md](docs/USAGE.md).

Документация для разработчика: [docs/BUILD.md](docs/BUILD.md) (сборка и тесты), [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), [docs/VMWARE.md](docs/VMWARE.md), [docs/STATUS.md](docs/STATUS.md).

## Возможности

- ПКМ по пустому месту: **Создать вм**, **Добавить вм**, **Удалить вм**, **Сеть вм** (Соединить напрямую / Соединить несколько / Удалить подключение).
- **Создать вм** — форма (имя, система, ISO, ОЗУ, ядра, диск, предназначение). Программа пишет .vmx, создаёт диск через `vmware-vdiskmanager` и открывает ВМ в VMware (она попадает в библиотеку). Новая ВМ получает адаптер NAT — провод к облаку «Интернет».
- **Добавить вм** — список ВМ из библиотеки VMware (`inventory.vmls`), галочки и предназначение для каждой.
- **Удалить вм** — «Убрать со схемы» (ВМ остаётся в VMware) или «Удалить с диска» (`vmrun deleteVM`; включённая ВМ выключается). После удаления с диска программа убирает свою копию `*.vmx.vvm.bak`, пустую папку ВМ и запись в библиотеке VMware. Если VMware открыт, запись из библиотеки нужно удалить вручную — программа подскажет это в строке состояния.
- **Соединить напрямую** — провод между двумя ВМ: обе получают адаптер в LAN segment `имя1-имя2`. Если сегмент с таким именем уже есть в VMware, берётся `имя1-имя2-2`, `-3`… Две ВМ, уже имеющие общий сегмент, повторно не соединяются. Провод к облаку — адаптер NAT.
- **Соединить несколько** — круг-сегмент с заданным именем; провода от круга к ВМ добавляют им этот LAN segment.
- **Удалить подключение** — удаляет у ВМ адаптеры этого подключения; удаление круга удаляет адаптеры у всех его ВМ.
- Провода строятся по .vmx: при открытии схемы, после каждой операции и по **F5**.
- Значки: роутер, сервер, клиент (ПК), облако. Точка у значка: зелёная — включена, серая — выключена, красная — файл не найден. Статус опрашивается каждые 3 с (`vmrun list`).
- Двойной щелчок по ВМ / «Открыть консоль» — открывает вкладку ВМ в VMware **без включения**. ПКМ по ВМ — Включить / Выключить / Открыть консоль / Удалить.
- «Выключить» спрашивает подтверждение, выключает мягко; если VMware Tools в гостевой ОС не запущены или мягко не вышло (с причиной: гостевая ОС ещё выключается / вывод `vmrun`), отдельно спрашивает про принудительное выключение (по умолчанию «Нет»).
- Схема сохраняется в файл `*.vvm` (меню «Файл»); последняя схема открывается при запуске. Если схема не открывается, программа один раз показывает ошибку и начинает новую схему; битая схема при следующих запусках больше не открывается.

## Как скачать и запустить

Программа **portable**: один файл **`VisualVMs.exe`** (~68 МБ), ничего устанавливать не нужно — ни саму программу, ни .NET (он уже внутри exe). **Права администратора не нужны**: программа работает с правами обычного пользователя и меняет только его файлы (`%APPDATA%`, файлы ВМ). Exe лежит в этом репозитории в папке [`dist`](dist/).

1. **Установите VMware Workstation 17.5 или новее** (если ещё не установлен) — это единственное требование.
2. **Скачайте программу:** откройте [`dist/VisualVMs.exe`](dist/VisualVMs.exe) → справа кнопка **«Download raw file»** (значок со стрелкой вниз). Файл сохранится в папку «Загрузки».
3. **Положите** `VisualVMs.exe` в любую папку, например `C:\Users\<вы>\Programs\VisualVMs\`, на другой диск или на флешку. Схемы и настройки хранятся отдельно, поэтому exe можно переносить.
4. **Запустите** двойным щелчком по `VisualVMs.exe`. Первый запуск может занять несколько секунд. Если Windows покажет «Windows защитила ваш компьютер» — нажмите **«Подробнее» → «Выполнить в любом случае»** (у файла нет цифровой подписи).
5. **Ярлык на рабочий стол:** ПКМ по `VisualVMs.exe` → «Отправить» → «Рабочий стол (создать ярлык)». В Windows 11: ПКМ → «Показать дополнительные параметры» → «Отправить».

Как пользоваться программой — в [docs/USAGE.md](docs/USAGE.md).

## Использование

Подробно, по шагам: [docs/USAGE.md](docs/USAGE.md). Кратко:

1. ПКМ по полю → «Добавить вм» (или «Создать вм»), отметить ВМ, выбрать предназначение.
2. ПКМ → «Сеть вм» → «Соединить напрямую», щёлкнуть два устройства (ВМ–ВМ, ВМ–облако). Для сети из нескольких ВМ: «Соединить несколько», ввести имя сегмента, затем щелчок по кругу и по ВМ.
3. Если ВМ включена, программа предложит её выключить перед изменением.
4. «Файл → Сохранить» — сохранить расположение значков (сеть уже записана в .vmx).

## Важно

- **Закройте вкладку ВМ в VMware перед изменением сети** (и перед удалением с диска): открытая вкладка может перезаписать .vmx. Если VMware открыт, программа предупреждает в строке состояния.
- Имена LAN-сегментов хранятся в `%APPDATA%\VMware\preferences.ini`. Открытый VMware Workstation может перезаписать этот файл, и имя сегмента пропадёт из VMware (сеть при этом работает). При открытии схемы, если VMware закрыт, программа восстанавливает имена сегментов из схемы.
- Перед первой правкой файла программа один раз создаёт рядом копию оригинала: `<вм>.vmx.vvm.bak`, `preferences.ini.vvm.bak`, `inventory.vmls.vvm.bak`. Существующая копия не перезаписывается — в ней всегда состояние до первого вмешательства программы.
- Не изменяются: приостановленные (suspended) и зашифрованные ВМ, а также файлы не в UTF-8 — их сеть меняйте в VMware.
- Изменения нескольких ВМ применяются «всё или ничего»: если запись одной ВМ не удалась, уже записанные возвращаются к исходному тексту.
