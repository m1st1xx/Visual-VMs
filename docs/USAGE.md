# Инструкция по использованию Visual VMs

Visual VMs рисует виртуальные машины VMware Workstation значками на поле (как устройства в Cisco Packet Tracer) и соединяет их «проводами». Каждый провод — это настоящий сетевой адаптер в настройках ВМ: программа сама меняет `.vmx` в VMware.

## 1. Установка и запуск

1. Нужны: Windows 10/11 x64, **VMware Workstation 17.5+**, **.NET 8 Desktop Runtime (x64)** — скачать: https://aka.ms/dotnet/8.0/windowsdesktop-runtime-win-x64.exe (или https://dotnet.microsoft.com/download/dotnet/8.0 → «.NET Desktop Runtime» → Windows x64).
2. Скачайте [`dist/VisualVMs.exe`](../dist/VisualVMs.exe) (на GitHub: открыть файл → кнопка «Download raw file»). Положите в любую папку, например `C:\Programs\VisualVMs\`.
3. Ярлык на рабочий стол: ПКМ по `VisualVMs.exe` → «Отправить» → «Рабочий стол (создать ярлык)».
4. Запустите. Установка не нужна. Если Windows SmartScreen предупредит о неизвестном издателе — «Подробнее» → «Выполнить в любом случае».

При первом запуске открывается пустая схема с облаком «Интернет».

## 2. Поле и устройства

| Значок | Что это |
|---|---|
| Роутер (диск со стрелками) | ВМ с предназначением «Роутер» |
| Сервер (стойка) | ВМ с предназначением «Сервер» |
| Монитор | ВМ с предназначением «Клиент (ПК)» |
| Облако | Интернет (NAT VMware) — одно на схему |
| Зелёный круг с именем | LAN-сегмент, к которому подключено несколько ВМ |

Точка у значка ВМ: **зелёная** — включена, **серая** — выключена, **красная** — файл `.vmx` не найден. Статус обновляется каждые 3 секунды.

Цвет провода: **синий** — прямое соединение двух ВМ, **зелёный** — провод к сегменту, **оранжевый** — NAT (интернет). Наведите мышь на провод — увидите имя сегмента.

- Перетаскивание значков и кругов — левой кнопкой мыши.
- **Esc** или ПКМ — отменить текущее действие (выбор устройства, протягивание провода).
- **F5** — перечитать настройки всех ВМ из VMware и перерисовать провода.
- Подсказки и ошибки показываются в строке состояния внизу окна.

## 3. Меню поля (ПКМ по пустому месту)

### Создать вм
1. ПКМ по месту, где должен появиться значок → «Создать вм».
2. Заполните форму:
   - **Имя** — без символов `" | \ / : * ? < >`;
   - **Система** — при выборе подставляются ОЗУ/ядра/диск по умолчанию;
   - **ISO-образ** — установочный образ (кнопка «Обзор…»);
   - **ОЗУ, МБ**, **Ядра**, **Диск, ГБ**;
   - **Предназначение** — роутер, сервер или клиент.
3. «Создать». ВМ создаётся в папке ВМ по умолчанию из настроек VMware (`<папка>\<имя>\<имя>.vmx`) и сразу открывается во вкладке VMware — там нажмите «Power on» и установите ОС.
4. Новая ВМ получает адаптер NAT — на схеме это оранжевый провод к облаку. Не нужен — удалите подключение (раздел 4).

Windows 11: программа включает EFI, Secure Boot и виртуальный TPM. Если установщик всё же пишет, что компьютер не подходит, — Shift+F10 в установщике и:
```
reg add HKLM\SYSTEM\Setup\LabConfig /v BypassTPMCheck /t REG_DWORD /d 1 /f
reg add HKLM\SYSTEM\Setup\LabConfig /v BypassSecureBootCheck /t REG_DWORD /d 1 /f
reg add HKLM\SYSTEM\Setup\LabConfig /v BypassRAMCheck /t REG_DWORD /d 1 /f
```

### Добавить вм
1. ПКМ → «Добавить вм». Откроется список ВМ из библиотеки VMware (уже добавленные на схему не показываются).
2. Отметьте галочками нужные ВМ и выберите каждой **предназначение**.
3. «Добавить». Значки встанут сеткой от точки щелчка, провода нарисуются сами по существующим настройкам:
   - две ВМ в одном LAN-сегменте — прямой провод;
   - три и больше ВМ (или одна) в сегменте — зелёный круг сегмента с проводами;
   - адаптер NAT — провод к облаку.

### Удалить вм
1. ПКМ → «Удалить вм» → щёлкните ВМ (или ПКМ по самой ВМ → «Удалить»).
2. Выберите:
   - **Убрать со схемы** — значок исчезает, ВМ в VMware остаётся;
   - **Удалить с диска** — ВМ удаляется из VMware **безвозвратно** вместе с файлами. Включённая ВМ сначала выключается.
3. Подтвердите. Перед удалением с диска **закройте вкладку этой ВМ в VMware**, иначе VMware не даст удалить.

### Сеть вм

**Соединить напрямую** (две ВМ одним проводом):
1. ПКМ → «Сеть вм» → «Соединить напрямую».
2. Щёлкните первое устройство — от него потянется провод.
3. Щёлкните второе устройство → подтвердите.
4. Обе ВМ получают новый адаптер в LAN segment с именем `имя1-имя2` (например `router1-router2`). Если такое имя уже занято, будет `router1-router2-2`.

Провод от ВМ к **облаку** добавляет ВМ адаптер NAT (выход в интернет через хост).

**Соединить несколько** (общий сегмент для нескольких ВМ, «свитч»):
1. ПКМ → «Сеть вм» → «Соединить несколько».
2. Введите имя сегмента (например `lan1`) → на поле появится круг.
3. Щёлкните по кругу — потянется провод — щёлкните ВМ → подтвердите. Повторите для каждой ВМ.
4. Все подключённые ВМ получают адаптер в LAN segment `lan1`.

**Удалить подключение**:
1. ПКМ → «Сеть вм» → «Удалить подключение», затем щёлкните провод (или просто ПКМ по проводу → «Удалить подключение»).
2. Подтвердите — у ВМ удаляется адаптер, который использовал это подключение.
3. Щелчок по кругу сегмента в этом режиме (или ПКМ по кругу → «Удалить сегмент») удаляет круг и адаптеры этого сегмента у всех ВМ.

## 4. Меню ВМ (ПКМ по значку ВМ)

- **Включить** — включает ВМ в фоне.
- **Выключить** — после подтверждения выключает мягко (через VMware Tools). Если Tools не установлены или ВМ не выключается, программа отдельно спросит, выключить ли принудительно (как выдернуть питание).
- **Открыть консоль** (или двойной щелчок по значку) — открывает ВМ во вкладке VMware, не включая её.
- **Удалить** — «Убрать со схемы» / «Удалить с диска».

## 5. Если ВМ включена

Сетевые адаптеры можно менять только у выключенной ВМ. Если при соединении или удалении провода ВМ включена, программа спросит «Выключить и применить?». «Нет» — ничего не меняется. Приостановленные (suspended) ВМ программа не меняет: включите и выключите их в VMware.

## 6. Схемы (меню «Файл»)

- **Сохранить / Сохранить как…** — сохраняет схему в файл `*.vvm`: расположение значков, предназначения, круги сегментов.
- **Открыть…** — открыть сохранённую схему. Провода при этом перечитываются из настроек ВМ.
- **Новая** — пустая схема.
- Последняя схема открывается автоматически при запуске. При закрытии с несохранёнными изменениями программа спросит, сохранить ли их (в заголовке окна такая схема помечена `*`).

Сами сетевые настройки хранятся в ВМ, а не в схеме: соединение остаётся в VMware, даже если схему не сохранить.

## 7. Советы и ограничения

- **Закрывайте вкладку ВМ в VMware перед изменением её сети.** Открытая вкладка может потом перезаписать настройки. Если VMware открыт, программа напоминает об этом в строке состояния.
- Имена LAN-сегментов хранятся в настройках VMware. Открытый VMware Workstation иногда перезаписывает их при закрытии: тогда имя сегмента пропадает из списка в VMware, но сеть продолжает работать. При открытии схемы (когда VMware закрыт) программа восстанавливает имена.
- Перед первой правкой программа сохраняет копию исходного файла: `<вм>.vmx.vvm.bak` рядом с ВМ, `preferences.ini.vvm.bak` и `inventory.vmls.vvm.bak` в `%APPDATA%\VMware`. Если что-то пошло не так — переименуйте копию обратно.
- Не более 10 сетевых адаптеров на ВМ (ограничение VMware).
- Адаптеры типа Bridged / Host-only на схеме не рисуются.
